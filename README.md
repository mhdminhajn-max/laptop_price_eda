
# Laptop Price Analysis — Exploratory Data Analysis

## Overview
This project explores laptop prices and hardware specifications
to understand how price varies across brands, RAM, processor
speed, storage, screen size, and weight.

## Objectives
- Inspect and clean the dataset
- Analyze laptop price distribution
- Compare median prices across brands
- Explore hardware specifications against price
- Examine correlations between numerical features
- Present findings through visualizations

## Tools
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

## Project Structure
- `laptop_price_eda.ipynb`: analysis notebook
- `outputs/figures/`: saved charts
- `data/`: local dataset folder

## How to Run
1. Install the dependencies with `pip install -r requirements.txt`.
2. Place your permitted CSV dataset in the `data/` folder.
3. Open `laptop_price_eda.ipynb` in Jupyter Notebook.
4. Run all cells from top to bottom.

## Dataset
The raw CSV is not included in this repository.
Place the dataset locally before running the notebook.

## Limitations
Findings depend on the dataset's quality, coverage, and units.
Correlation does not establish causation.
